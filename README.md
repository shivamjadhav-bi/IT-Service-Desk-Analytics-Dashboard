\# IT Service Desk Performance \& SLA Analytics Dashboard



\## Project Overview



An end-to-end data analytics portfolio project developed to analyse IT service desk ticket performance, resolution trends, workload distribution, and SLA compliance using a sample dataset of 20,000 tickets.



The objective is to transform raw ticket data into meaningful insights that can help IT managers monitor service desk performance and identify areas for improvement.



\## Tools \& Technologies



\- \*\*Microsoft Excel\*\* – Initial data inspection and validation

\- \*\*MySQL\*\* – Data validation, SQL queries, and analysis

\- \*\*Power Query\*\* – Data cleaning and transformation

\- \*\*Power BI\*\* – Interactive dashboard and visualisation

\- \*\*DAX\*\* – KPI calculations and analytical measures



\## Dataset Details



\- Total Records: 20,000 tickets

\- Date Range: January 2025 – August 2026

\- Locations: Mumbai, Bangalore, Chennai, NSL 1, NSL 2, Mohali, Vizag, Coimbatore

\- Departments: IT Helpdesk, IT Network, IT Server, Desktop Support

\- Priorities: P1, P2, P3, P4



\*Note: This project uses a self-created sample dataset. No confidential company or production data is included.\*



\## Project Workflow



1\. \*\*Data Validation:\*\* Checked duplicate ticket IDs, missing values, data quality, and date ranges.

2\. \*\*Overall Ticket Analysis:\*\* Analysed ticket volume, status distribution, resolution rate, and average resolution time.

3\. \*\*Location Analysis:\*\* Compared ticket volume, resolution performance, and workload across locations.

4\. \*\*Department Analysis:\*\* Evaluated ticket distribution and resolution performance by department.

5\. \*\*Engineer Analysis:\*\* Analysed engineer-wise ticket assignments and resolutions.

6\. \*\*SLA Analysis:\*\* Evaluated SLA compliance and breaches based on ticket priority.

7\. \*\*Resolution Analysis:\*\* Analysed resolution time and ticket resolution patterns.

8\. \*\*Power BI Preparation:\*\* Prepared the final SQL view for Power BI reporting.

\## Key Insights



\- Overall ticket resolution rate was 77.59%.

\- SLA compliance was 51.87% among resolved tickets with available resolution-time data.

\- P1 tickets had the highest SLA compliance at 60.26%.

\- IT Helpdesk generated the highest ticket volume among the departments.

\- The analysis provides visibility into ticket workload, resolution performance, and SLA improvement opportunities.
